# digivote-web

Static marketing site for DigiVote, hosted on Firebase Hosting (`digivote-prod`).

- Live URL: https://digivote-prod.web.app
- Project: `digivote-prod`
- Deploy: `firebase deploy --only hosting --project digivote-prod` (from this folder)

This is **not** the Flutter app (`digivote-ui`) and **not** the API (`digivote-backend`).
